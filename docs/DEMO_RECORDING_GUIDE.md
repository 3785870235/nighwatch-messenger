# 午夜光术学院：3分钟演示录制提纲

状态：录制指南，不是已制作的视频。用户负责录制，Codex不生成视频。已按2026-10-13五章发布构建核对；未实装功能不出现在演示承诺中。

## 开拍前

1. 用最终交付包启动游戏，先走一遍要演示的路径；使用单独演示存档，不覆盖日常存档。
2. 准备一份已解锁档案门的演示进度，以及一份接近完成、可最后补线并检验的演示术式。使用准备好的进度需在画面或解说标明；不要伪装成从零通关。
3. 使用熟悉的录屏工具，只录游戏窗口，关闭无关消息通知。建议1920×1080、30fps；先试录10秒，确认游戏音量低于讲话声、中文字清晰。
4. 控制在2分40秒到2分55秒，给3分钟上限留余量。无需展示整个序幕，无需演完所有章节。

## 录制时的重点

- 保留至少一次“鼠标操作→实际结果变化→推理”的连续镜头。花最多时间证明知识能被操作和发现，而非展示静态美术。
- 不必念AND/XOR等全部术语；解释清楚玩家改变了什么、观察到什么、为什么排除一种解释。
- 若能顺畅展示一次错误预测/反例，会更直观；不要为了制造错误破坏存档。
- 演示使用最终构建。不要将概念图、新角色素材或尚未接入的章节点成已完成。
- 仅报告实际可玩章数和已验证功能。本版五章均已实现，此提纲仍以档案门为主。可将2:10–2:30替换为准备好的第五章存档：展示高低两盏星灯的检验单，以及「天亮了 · 回到学院 →」。明确这是预先准备的进度，不在三分钟内假装从头通关五章。
- 如讲技术取舍，可用一句话：“复用稳定的仿真底座，把开发时间用于调查玩法和新手引导。”上游代码和团队新增部分应与README一致。
