# 午夜光术学院 · 世界观设定（关卡模式的唯一口径）

状态：2026-10-12 由 Claude 起草；2026-10-13 补齐第一、二、四、五章和「那一夜」全貌。本文件约束所有前台文案、对白、美术。与代码冲突时以本文件为准并修改代码；与 `USER_REQUIREMENTS.md` 冲突时以用户要求为准并修改本文件。各章对白的原文在 `levels/<章>/story.properties`，本文件只记口径。

## 1. 光术的物理规则（不许违反）

| 概念 | 设定 | 前台说法 |
|---|---|---|
| 讯线 | 符文之间传递讯息的光线。亮 = 「是」，暗 = 「否」。 | 讯线、讯息 |
| 无讯 | 讯线被切断、没接上、没送到时，它**什么也不传**。无讯不是「否」。 | 无讯不作否 |
| 钥印 | 每个岗位值夜人随身持有的印。**钥印不在讯线里跑**；讯线只传「岗位持有钥印」这句报告成立与否。 | 1 = 岗位持有钥印 |
| 符文 | 由灵契绑定的机关，只听讯线，按自己的规矩回应。规矩稳定、可重复，不随剧情改变。 | 符文、术式 |
| 反相符文 | 把一条讯线的说法反过来：收到「是」放出「否」，收到「否」放出「是」。提醒灯用它。 | 反相符文 |
| 双印符文 | 两条讯线都传来「是」才放行；只要有一条是「否」就不放行。档案门的锁纹、高星灯用它。 | 双印符文 |
| 单席符文 | 两条讯线说法不同时才放行；都是「是」或都是「否」，都不放行。受理灯、低星灯用它。 | 单席符文 |
| 锁纹 | 档案门内的主符文。靠门的**校准页**校准；校准页离开门，锁纹会在天亮前熄灭。 | 锁纹 |
| 校准页 | 门的自记页。门每开启一次，就在当时那一格烙下一道光痕。它记「门开过」，**不记是谁开的**。 | 校准页、光痕 |
| 星灯 | 校准塔顶的两盏灯，一高一低，一起回答一轮报告。读数 = 高星灯记 2、低星灯记 1：都暗 0，只亮低 1，只亮高 2，两盏都亮 3。**高星灯一盏，记两个人**。 | 高星灯、低星灯 |
| 封盒 | 校准塔里两根铜讯管先钻进的同一个盒子；出了封盒各接哪一盏星灯，从外面看不见。 | 封盒 |
| 试讯台 | 器物前的试验台：在两个岗位位置放上或取下钥印，把报告送进去，看它怎样回应。灯章只有岗位 A 一个位置。 | 门前 / 灯前 / 登记台前 / 塔前试讯 |
| 许可印 | 术式里把回应交给器物的那一处。术式里没有许可印，或许可印没接上讯线，器物就收不到任何回应（是无讯，不是「门不开」「灯暗」）。 | 许可印 |
| 学院检验处 | 学院里试讯新术式的地方。**不动学徒的原稿**，照原稿另刻一份副本，把本章每一种岗位情形逐一送进副本，记下它的回应，再写回信。学徒自带的试讯单不作数。 | 学院检验处、送检 |
| 副本 | 检验处照学徒原稿刻出的复制品，只用来试讯。副本立不起来（有地方没接上）或运转不起来（讯线互相顶撞、来回打转）时，一种情形也不试，也不猜。 | 副本 |
| 试讯单 | 回信附的单子，每种情形一行：岗位是否持钥印、本章规矩（门规 / 灯规 / 席规 / 塔规）该怎样、副本怎样回应。不合规矩的那一格用红笔圈出；副本无讯时写「无讯」，绝不写「门不开」「灯暗」。星灯章每种情形分高、低两行，行首写灯名（「高星灯 亮」）；单子末尾数的是**情形**，不是行数。 | 试讯单 |

推理铁律：

1. 只有亲眼观察到的回应才算证据；没观察的组合不算支持也不算反驳。
2. 一张残页只要有一组亲眼记录和它的说法相反，就被推翻。
3. 记录完整不等于事实完整；「没收到」不等于「不成立」。

前台只用符文 / 钥印 / 讯线 / 术式的说法，不出现任何真实电路术语（门电路名、真值表、课程名等）。

## 2. 人物

- **玩家 · 值夜学徒**：第一夜值班。不凭说明书下结论，只凭亲眼证据。
- **芙 · 巡夜信使**：讯线失灵时替岗位送信。关心失联的人，推动调查。只转述信件，不替信作证。B 的手书写给档案馆，第三章之前一直封着——所以灯章里芙不用「读信」姿势。
- **微光 · 档案精灵**：折纸做的精灵，只记得自己亲眼看见的事。口头禅「先听见，再相信」。不提前报答案；玩家做出判断后，才把证据念出来。
- **洛 · 守档人**：守着档案秩序，相信书面记录。会在「记录完整是否等于事实完整」上和玩家冲突，最终亲手翻出底稿，并在最后一章把「不知道」写进记录。全剧没有证据说他在藏东西——灯章里他不用「回避」姿势。

## 3. 第一章 · 值房的灯：报告灯

零点以后，值房墙上岗位 A、B 的报告灯一盏也没亮。B 的信筒里有一封封口的信，写明送档案馆；A 那边什么消息也没有。《灯规》报告灯那页不见了，两盏灯的旧术式都褪了色。本章只重刻 A 那盏，试讯台只有岗位 A 一个位置。

| 残页 | 说法 | 来历 | 疑点 |
|---|---|---|---|
| 甲 · 照报告亮（真） | 持钥印灯亮，未持灯暗。讯线直接接到许可印，不经过任何符文。 | 夹在值房交接簿里，上一任值夜人的笔迹。 | 上一任才来一个月，自己也常记错。 |
| 乙 · 反着亮 | 未持钥印灯才亮。 | 从《灯规》书脊里抖出来，边角有水渍。 | 没写灯名，也许说的是另一盏灯。 |
| 丙 · 讯线接着就亮 | 讯线接上就一直亮，不管报告说什么。 | 钉在值房门背后，下半页被撕掉。 | 撕掉的半页也许还写着别的条件。 |

证据语义：A 持钥印那一次只推翻乙；A 未持那一次同时推翻乙、丙。

线索：A、B 两盏都照新术式重刻、接回讯线，还是暗的。洛要记「A、B 都是否」，微光拦下：灯只有收到「是」才亮，讯线什么也没送来时一样亮不起来。值房记录表只有「是」「否」两格，没有「没送到」——先空着，旁边写清楚。

- 已知：报告灯的规矩（亲眼证实）；灯暗可能是「否」，也可能是没送到。
- 未知：A、B 在不在岗。
- 引向第二章：讯线出了值房，先到芙的信使站。

## 4. 第二章 · 不响的铃：提醒灯

讯线出了值房先经过信使站的灯板，再送去记录台。提醒灯一亮，芙的铃就响；今晚铃一次也没响，A、B 的提醒灯都暗着。《器物登记册》写着「提醒灯，已停用」。本章重刻 A 那盏提醒灯。

| 残页 | 说法 | 来历 | 疑点 |
|---|---|---|---|
| 甲 · 缺印就亮（真） | 未持钥印灯亮，持有灯暗。讯线先经过反相符文。 | 夹在巡夜手册提醒灯那页，字迹工整。 | 手册是发给新生的简本，不一定写全。 |
| 乙 · 持印就亮 | 持钥印灯亮。 | 从芙的信袋里翻出来，纸角折过。 | 芙刚入职时发的，记不清写的是不是提醒灯。 |
| 丙 · 已停用 | 灯已停用，永远不亮。 | 洛从《器物登记册》抄下的一条。 | 登记册别的条目都有日期，只有这条没有。 |

证据语义：A 未持钥印那一次同时推翻乙、丙；A 持钥印那一次只推翻乙。

线索：提醒灯没有停用；登记册那一条的墨色比整页都新，是后补的。把两盏灯合起来看：A 持钥印，报告灯该亮；不持，提醒灯该亮——讯线一路通到这里，总有一盏会亮。两盏都没亮，所以 A 的报告没有送到信使站。B 的两盏灯也整夜暗着。

- 已知：提醒灯的规矩（亲眼证实）；它没有停用；「已停用」是后补的；零点以后讯线没把报告送到信使站。
- 未知：A 在不在岗（报告灯照实暗着，还是讯线在值房前就断了，分不出来）；谁补的「已停用」、为什么；讯线为什么送不到。
- 引向第三章：只能靠信了——把 B 的手书送去档案馆，和巡夜记录对一对。

## 5. 第三章 · 档案门

那一夜在档案门这一处实际发生的事（作者视角，前台只能一步步露出）：

1. 零点整，岗位 A、B 的值夜人都在岗，钥印在手。两份报告都成立。
2. 档案门的锁纹按「双印」规矩运行：两份报告都成立才放行。所以零点时门开了一次，校准页烙下一道光痕。
3. 通往巡夜记录台的讯线那晚是暗的（原因未知）。记录台底稿上，两栏都写着「尚未收到报告」。
4. 有人把两栏都改填成「否」，正式记录就成了「两人都已撤离，门整夜没开」。
5. 有人撕下校准页，塞进门框夹层。锁纹失去校准，天亮前会熄灭——这就是本章必须修复的原因。
6. B 发现讯线不亮，写了手书托芙送出：零点整，在岗，钥印在手。

### 三张残页（《门规》被水浸后找回）

每页都有来历和疑点，**分量相当，不能靠来历猜出答案**，只能靠门前证据。

| 残页 | 说法 | 来历 | 疑点 |
|---|---|---|---|
| 甲 · 任一印 | 只要有一份报告成立，门就开启。 | 夹在水浸的《门规》册里，字迹最完整。 | 纸比册子新，像是后来补抄的。 |
| 乙 · 双印（真） | 两份报告都成立，门才开启。 | 粘在门框背面，墨迹晕开了一半。 | 「都」字晕得厉害，也可能是「有」字。 |
| 丙 · 单席印 | 恰好一份报告成立，门才开启；两份都成立反而不开。 | 洛在登记台抽屉里找到，盖着档案馆旧章。 | 登记台也用这枚旧章——它说的可能是别的门。 |

丙的疑点是第四章（单席登记台）的伏笔：它在档案门前是错的，在登记台却是真的。

### 本章的因果链

序幕（B 的手书和巡夜记录对不上）→ 疑点对白（需要门规；校准页失踪，锁纹将熄）→ 逐页翻看残页并选出判断 → 门前试讯，用亲眼记录推翻说错的残页 → 选对且证据充分才能刻新术式 → 术式通过可信检验 → 刻纹时找回校准页 → 用证实的规矩反推：零点 A、B 都持有钥印 → 底稿露出「尚未收到报告」→ 结论「没收到，不等于不成立」→ 留下未知（谁改的、谁撕的、讯线为何不亮）→ 芙带出第四章：登记台同一席位登记了两个人。

### 已知 / 未知（结尾必须分开说）

- 已知：门的规矩（亲眼证实）；零点门开过（校准页）；所以零点 A、B 都持有钥印；记录台没收到报告。
- 未知：谁把「尚未收到」改成「否」；谁撕下校准页；讯线为何不亮。

## 6. 第四章 · 单席登记台：受理灯

档案馆前厅的登记台，守门席每夜只有一个，谁来值守先在这里登记，台上的受理灯回答每一轮登记。登记册零点那一行并排签着 A、B，旁注「正常」。《席规》也残了，受理灯底座的旧术式裂了一道缝。

| 残页 | 说法 | 来历 | 疑点 |
|---|---|---|---|
| 甲 · 有人来领就受理 | 有一个岗位持钥印来领，受理灯就亮。 | 刻在登记台《登记须知》铜牌上，字口清楚。 | 铜牌角上一行小字被铜锈盖住了。 |
| 乙 · 两人联签 | 两个都持钥印才亮；只来一个不受理。 | 就是那晚的登记册：零点那行并签 A、B，旁注「正常」。 | 旁注笔迹和登记册别的页都不一样。 |
| 丙 · 单席印（真） | 恰好一个持钥印才亮；两个一起来，这一轮谁也不受理。单席符文。 | 档案门前划掉的那一张，洛当初在登记台抽屉里找到它。 | 在档案门前它已经被证据推翻过一次。 |

证据语义：两人都未持分不出任何残页；只有一人持钥印推翻乙；两人都持同时推翻甲和乙。

两个都持钥印时灯暗，是**这一轮不受理**，不是钥印没了——一个席位不能同时记给两个人。

线索：零点那一轮受理灯应该是暗的。刻纹时，洛在受理灯底座里摸到零点那一轮的存根，盖的是「未受理」。有人把两人的登记并成一行，把「未受理」写成了「正常」——和「尚未收到」被写成「否」一样：记录看起来完整，却不诚实。

- 已知：单席登记的规矩（亲眼证实）；零点那一轮没有受理（存根）；登记册那一行是被并成「正常」的。
- 未知：谁并的这一行、为什么这样写。
- 引向第五章：校准塔的星灯要把每一份报告如实数出来。

## 7. 第五章 · 星灯归位：校准塔

天快亮了。校准塔顶挂着两盏星灯，一高一低，两个岗位的报告最后都送到这里，由星灯数出今夜几个人在岗。塔楼日志零点那一格写着「亮了一盏，记 一人在岗」，没写亮的是哪一盏。《塔规》也残了，封盒里的旧术式裂了——本章要给两盏星灯各刻一道新术式。

| 残页 | 说法 | 来历 | 疑点 |
|---|---|---|---|
| 甲 · 几人几盏 | 一个人亮低星灯，两个人两盏都亮。 | 塔楼日志一直这样读灯，往前好几页都是亮一盏记一人、亮两盏记两人。 | 日志是值夜人手记，不是《塔规》原文；也从没写过亮的是哪一盏。 |
| 乙 · 一岗一灯 | A 持钥印亮低星灯；B 持钥印亮高星灯。 | 塔里两根铜讯管：A 那根挨着低星灯，B 那根挨着高星灯。 | 两根讯管都先钻进同一个封盒，出来各接哪一盏看不见。 |
| 丙 · 低星让位（真） | 恰好一个持钥印只亮低星灯；两个都持，低星灯让位，只亮高星灯。低星灯是单席符文，高星灯是双印符文。 | 洛在塔基拓下的建塔铭文，一笔一画都在。 | 拓片缺了一角，「高」字只拓出半边。 |

证据语义：两人都未持、只有 A 持钥印，都分不出任何残页；只有 B 持钥印推翻乙；两人都持同时推翻甲和乙。玩家必须两盏灯都看清，亮的是哪一盏、暗的是哪一盏。

线索：「亮了一盏」可能是一个人，也可能是两个人，得看是哪一盏。日志里「亮了一盏」是看见的，「一人在岗」是推出来的——推的那一步把「一盏」直接当成了「一个人」。三处放在一起：登记台「未受理」= 没人来或两人一起来；星灯亮一盏 = 一人或两人；两处能同时说通的只有「两个人」，档案门的光痕也这么说。三处记录各凭各的规矩，指向同一个答案。

- 已知：星灯计数的规矩（亲眼证实）；零点亮的是高星灯，在岗的是两个人。
- 未知：谁写的日志、为什么只写了一半。
- 结尾：洛把全夜排一遍（见 §8 的已知 / 未知），说「记录完整，不等于事实完整。这一回，我把『不知道』也写进记录里」；芙说 B 的手书现在不只是一封信这么说了，天亮了，把这一夜的记录送回档案馆。

## 8. 五章总线与那一夜

报告灯（值房）→ 提醒灯（信使站）→ 档案门 → 单席登记台 → 星灯归位（校准塔）。每章修好一个符文、找回一条线索，最后用玩家自己的检验重建那一夜的报告链。

开放顺序：五章按顺序开放。一章通过（本次会话内通过，或已存档的通过）就开放下一章；不通过不开放。本次会话内刚通过时，检验处回信上有「下一章：<章名> →」，未读的线索先读完再进下一章；最后一章的按钮是「天亮了 · 回到学院 →」，读完线索回到学院首页。早先存档里的通过不显示这个按钮。

那一夜（作者视角，五章合起来能露出的全部）：

1. 零点整，A、B 都在岗，钥印在手。
2. 值房 → 信使站 → 记录台这一路讯线那晚是暗的：报告灯、提醒灯都没亮，芙的铃没响，记录台底稿写「尚未收到报告」。原因未知。
3. 档案门、登记台、校准塔收到了报告：门开了一次（光痕）；登记台这一轮不受理（存根「未受理」）；高星灯亮了。

## 9. 美术与界面口径

- 像文字 RPG：人物名牌 + 立绘 + 打字机对白，点击推进；纸质物件（信、残页、校准页）都画成实物，有纸纹、水渍、撕边。
- 一屏只讲一件事；每次换屏都有过场；动效、声音可关，暂停停在当前画面。
- 残页**一张一张翻**，不并排；判断前不显示任何「推翻 / 成立」，选定后只在所选那页盖印，由微光念出证据。
- 手写体只用于短标题和署名，正文用清晰的无衬线字体。
- 检验结果是**学院检验处的回信**，放在阅览桌上，不是报表：全部合乎本章规矩——署名旁压一枚火漆封印；有不合的情形——盖「退回重刻」朱印并用回形针别一张试讯单；副本立不起来——不附试讯单，只说哪里没接上，并重申无讯不作否。等待送检、检验中、原稿已改动（回信失效）是不带「此复」的便条。
- 水渍、撕边只属于被水浸过的**旧纸**（残页、《门规》）；回信和试讯单是当夜新写的，纸面干净，没有水渍。
- 场景里的灯会忽明忽暗地闪，星星会明显闪烁；关掉动效时画面静止。星灯房间里星灯缩小（0.86 倍）挂高，铭牌和封盒都在过场字幕之上。
